# 🚩 ロゴ

アプリごとのロゴ（形）は各アプリで決める。souan に決めるのは、どのアプリのロゴにも共通する作り方と色の決まり。

## 🖌️ 色

- ロゴのアイコンは**役割の色の変数で塗る**（`var(--color-accent)`・`var(--color-accent-strong)`・`var(--color-info)`・`currentColor` など）。色の値を直接書かない。テーマを変えるとロゴの色も一緒に変わる
- 線や竿など文字の色に合わせる部分は `currentColor` にし、ロゴを置く場所の文字色（`--color-text`）を受ける
- 塗りは平らにする（グラデーション・影・立体の表現を使わない）。面を分けて見せたいときは、アクセントとアクセント（濃）の 2 色で塗り分ける
- 例: 折り紙の旗のロゴなら、旗の面をアクセントの 2 色で塗り分けて折り目を見せ、竿は文字の色（`currentColor`）にする

## 🔤 ロゴの文字

- アイコンとアプリの名前を横に並べる。名前は Fraunces（太さ 500・`"SOFT" 50`・字間 `0.02em`）、アイコンの高さは文字の 1.3 倍（`docs/typography.md`）
- ヘッダーではトップへのリンクにし、`aria-label="<アプリ名> ホーム"`。アイコンは `aria-hidden`

## 🔖 ファビコンとアプリのアイコン

- ファビコンは SVG で作り、アプリの中のロゴと同じ形にする。片方の形を変えたら、もう片方（と `apple-touch-icon.png` など）も同じ形に作り直す
- ファビコンの SVG は CSS 変数を読めないので、色の値を書く。ライトは白紙の値、`@media (prefers-color-scheme: dark)` の中で夜更かしの値に切り替える
- **16px で形が分かることを確かめる**。細い線や細かい模様は 16px でつぶれるので、小さい表示では線を省いた版を用意するか、形を太く単純にする。確かめるときは 16px・32px に縮めた画像をヘッドレスのブラウザで撮って見る
- ホーム画面用の PNG（180px・192px・512px）は背景を透過しない（OS が黒や白を敷いて見え方が変わるため）。背景は白紙のベース色

## 📦 見本について

- souan の見本（`samples/*.html`）のヘッダーにある紙を重ねたアイコンは、仮のロゴ。souan はロゴの SVG を持たない
- 各アプリのロゴは各アプリのリポジトリで管理する

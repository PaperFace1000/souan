# 🧱 画面の組み立てと中身の見せ方

見本は `samples/patterns.html`。1 つ 1 つの部品の決まりは `docs/components.md`、画面の幅と列の組み方は `docs/layout.md`。

## 📑 タブ

同じページの中で中身を切り替える。React Aria の `Tabs` / `TabList` / `Tab` / `TabPanel` で作る（←→・Home・End で移れて、読み上げで何枚目か分かる）。

| 大きさ | 文字 | 余白 | タブの間 | 使いどころ |
|---|---|---|---|---|
| 普通 | 14px | 8px 14px | 4px | ページの中の切り替え |
| 小さい | 13px | 8px 10px（並びの左右に 8px） | 2px | 横の欄の中の切り替え |

- 下線式。並びの下に `border` の 1px の線を引き、タブは `margin-bottom: -1px` でその線に重ねる
- 選んだタブは下に `accent-strong` の 2px の線、文字を `accent-strong` の太字。ほかは `muted` で、なぞると `text`
- 先頭にアイコン 16px、文字との間は普通 6px・小さい 4px
- 入りきらないときは**並びの中だけ横にスクロール**する（`overflow-x: auto`、スクロールバーは隠す）。ページに横スクロールを出さない。選んだタブは見える位置まで送る
- 小さいタブは、欄の幅が 480px 以下ならアイコンを外し、余白を 8px 6px に詰める
- フォーカスはキーボードのときだけ、`accent` の輪 2px を内側（`outline-offset: -2px`）に、角 6px で出す
- 選んだタブは、残す意味があれば URL に残す（再読み込み・戻るでも同じタブを開く）
- 中身の読み込み中は、パネルの中だけに読み込みの表示を出す（ページ全体を隠さない）
- アプリによって、タブの間（4px と 2px）・アイコンの大きさ（16px と 15px）・下線を重ねるかが違った。上の表の値を正にした（アイコンは `docs/components.md` の段階に合わせて 16px）

## 🗄️ サイドバー・引き出し・幅のつまみ

フォルダやページの一覧を左に置く画面の作り。`docs/layout.md` の「本文の枠」の詳しい決まり。

| 項目 | 値 |
|---|---|
| 幅 | 既定 280px。つまみで 200〜560px（画面の幅の半分まで） |
| 見た目 | 背景 `surface`、右に `border` の 1px の線、余白 12px 8px 40px |
| 位置 | ヘッダーの下に固定（`position: sticky; top: 56px; height: calc(100dvh - 56px)`）、中だけ縦にスクロール |
| 見出し | 12px・太さ 600・字間 0.04em・`muted` |

**幅のつまみ**

- サイドバーの右端に幅 6px（線の真ん中に来るよう `left: 幅 - 3px`）、`cursor: col-resize`
- 普段は見えず、なぞる・フォーカス・ドラッグ中だけ中央 2px に `accent` の線を出す（0.15s で変える）
- ドラッグ（マウス・タッチ。`touch-action: none`）、←→ で 16px（Shift で 4 倍）、Home で最小・End で最大、ダブルクリックで 280px に戻す
- `role="separator"`・`aria-orientation="vertical"`・`aria-label`（「ノートの一覧の幅」など）・`aria-controls`・`aria-valuenow` / `aria-valuemin` / `aria-valuemax`・`tabindex="0"`。`title` に操作の説明
- ドラッグの間は本文の文字が選ばれないようにする（`body` に印を付けて `user-select: none`）
- 幅は保存し、全ページ・ほかのタブで同じにする。保存できないときはそのタブの中だけ覚える

**引き出し（899px 以下）**

- サイドバーを左から出る引き出しにする。幅 `min(320px, 85vw)`、影 `4px 0 16px rgb(0 0 0 / 0.12)`、`z-index: 15`
- 閉じている間は `transform: translateX(-100%)` と `visibility: hidden`（読み上げやフォーカスが入らない）。開け閉めは 0.2s
- 後ろに幕（`rgb(0 0 0 / 0.3)`、`z-index: 14`）。幕・Esc・ページを移ったときに閉じる
- ヘッダーの左端に開け閉めのボタン（`Menu` ⇔ `X`）。`aria-expanded`・`aria-controls`、`aria-label` は「〜を開く」⇔「〜を閉じる」
- つまみは出さない。本文の余白は 20px 16px 64px
- `prefers-reduced-motion: reduce` では動かさない（`transition: none`）

## 🌳 ツリー

フォルダとページの入れ子の一覧。

| 項目 | 値 |
|---|---|
| 行 | 高さ 32px 以上、余白 4px 8px（左は 8px + 深さ × 14px）、角 6px、14px・行間 1.4、間 4px |
| なぞったとき | 背景 `base` |
| 開いているページ | 背景 `color-mix(in srgb, var(--color-accent) 28%, transparent)`、太さ 600 |
| アイコン | 開け閉めの矢印 14px（`ChevronRight` ⇔ `ChevronDown`）、フォルダ・ページ 16px（`muted`） |

- 開いているページは**背景と太さだけ**で示す。左の縦線や色付きの文字は使わない（なぞっても見た目を変えない）
- 開いているページの行は、アイコンと 2 段目の文字も `text` にする（`muted` のままでは背景の上で 4.5 に届かないテーマがある）。背景の色を変えるときは 7 テーマで比を確かめる
- ページの名前は 2 段: 1 段目にファイル名（12px・太さ 400・`muted`・行間 1.3）、2 段目に最初の見出し。どちらも 1 行で省略する。見出しが無ければ 1 段だけ
- 矢印の無いページの行は、矢印の分（14px）の空きを入れて名前の位置をそろえる
- フォルダの行の右端に「+」（新しいページ、28px 四方、角 6px）。**なぞったときとフォーカス中だけ**出す（`opacity`）。ホバーできない端末（`hover: none`）では常に出す
- フォルダの行は `button` で `aria-expanded`。開いているページは `aria-current="page"`。2 段の行は `aria-label` に両方の名前を入れる。「+」には「〜に新しいページを作る」の `aria-label`
- アプリによって 2 段目の文字が 11.5px だった。文字の段階（`docs/typography.md`）に合わせて 12px を正にした

## 🧭 目次

長いページの見出しへのリンクの一覧。`nav` に `aria-label="目次"`。

| 画面 | 置き方 | 見た目 |
|---|---|---|
| 広い（1200px 以上） | 本文の右の列（15rem、本文との間 40px）に固定（`position: sticky; top: 72px`）。高すぎれば中だけスクロール | 13px・行間 1.5 |
| 狭い（1199px 以下） | 本文の上に、**閉じた**箱で置く | 余白 6px 12px（開くと下 10px）、枠 `border`、角 8px、背景 `surface`、14px |

- 先頭に「目次」の開け閉めのボタン（太さ 600・`muted`、なぞると `accent-strong`、矢印 14px）。`aria-expanded`、開いているときだけ `aria-controls`
- 一覧は左に `border` の 1px の線、線との間 10px、項目の間 6px。見出しの深さ 1 段ごとに 12px 字下げ（一番浅い見出しを 0 段とする）
- リンクは `text` の色で下線なし。なぞると `accent-strong` と下線
- 広い画面の開閉は保存して次も同じにする。狭い画面は毎回閉じた状態から始め、項目を押したら閉じてから見出しへ移る（閉じると本文の位置がずれるため）
- 見出しが無いページでは出さない

## 🔎 検索のダイアログ

ページを語で探すダイアログ。React Aria の `ModalOverlay` / `Modal` / `Dialog` で作り、入力欄は `role="combobox"`、結果は `role="listbox"`。

| 項目 | 値 |
|---|---|
| 位置 | 画面の上から 10vh、左右の中央（`ModalDialog` と違い、上に寄せる。結果が増えても入力欄が動かない） |
| 幅 | `min(640px, 100%)`、高さは最大 80vh |
| 見た目 | 角 14px、枠 `border`、背景 `base`、影と幕は `ModalDialog` と同じ |
| 入力の行 | 余白 8px 8px 8px 14px、下に `border` の線。虫めがね 18px（`muted`）、入力欄は 16px（iOS で拡大されない大きさ）、右に閉じるボタン 40px 四方 |
| 状態の文 | 13px・`muted`・余白 8px 14px、`role="status"`（「3 件」「検索中…」「上位 50 件（全 120 件）」など） |
| 結果の行 | 余白 8px 10px、角 8px。題名は太さ 600、場所は 12px・`muted`、抜き出しは 13px・行間 1.6 |
| 選んでいる行 | 背景 `surface`、左の内側に 3px の線（`box-shadow: inset 3px 0 0 var(--color-accent-strong)`） |
| 一致した語 | `<mark>` に背景 `warning-bg`、文字 `text`、角 2px、外に 1px の `warning-border` |
| 操作の説明 | 下に 12px・`muted`。キーは `<kbd>`（枠 `border`、角 4px、背景 `surface`）。`aria-hidden`（読み上げには入力欄の役割で伝わる） |

- **幅 640px は検索のダイアログだけの例外**とする（入力欄と抜き出しの文を 1 行で読める幅が要るため）。ほかのダイアログは `ModalDialog` の 440px / 880px
- フォーカスは入力欄に置いたまま、↑↓ で選ぶ行を動かす（`aria-activedescendant`）。Enter で開き、Esc で閉じる。日本語の変換中の Enter・矢印は変換の操作として扱い、検索の操作にしない
- 次の語の結果を待っている間は、前の結果を薄く（`opacity: 0.6`）出し、`aria-busy` を付ける
- 長い題名・場所は `overflow-wrap: anywhere`
- **599px 以下では全画面**（幅 100%・高さ `100dvh`・枠と角なし）にし、操作の説明を隠す
- 外側のクリックで閉じてよい（入力が消えても困らない、すぐ開き直せるダイアログのため。`ModalDialog` の「閉じない」の例外）
- アプリでは角 12px・幕 `rgb(0 0 0 / 0.3)`・影 `0 12px 32px rgb(0 0 0 / 0.2)` だった。幅のほかは `ModalDialog` とそろえ、**角 14px・幕と影も `ModalDialog` の値**を正にした（ダイアログの角は 14px、と `docs/layout.md` の表で決めているため。例外は幅だけに絞る）

## 🃏 カード

お気に入りのように、行き先を少し大きく並べる。

| 項目 | 値 |
|---|---|
| 並べ方 | `grid-template-columns: repeat(auto-fill, minmax(min(100%, 14rem), 1fr))`、間 8px |
| カード | 余白 10px 12px、角 10px、枠 `border`、背景 `surface`、中の間 2px、高さはそろえる（`height: 100%`） |
| 名前 | 太さ 600 |
| 補足（場所など） | 12px・`muted` |

- カード全体を 1 つのリンクにする。なぞると枠を `accent`
- 長い名前は省略せず `overflow-wrap: anywhere` で折り返す。全文（場所）は `title` にも入れる
- 行き先が無くなったものはリンクにせず、文字を `muted`、名前に取り消し線、補足の先頭に「見つかりません」（11px・`danger`）
- 1 件も無いときは、カードの代わりに追加の仕方を 1 行で書く
- `min(100%, 14rem)` にして、360px の幅でも 1 列で収める

## 🔄 ヘッダーの状態の小ボタン

同期などの状態をヘッダーに小さく出し、押すと詳しい中身を出す。React Aria の `DialogTrigger` と `Popover`・`Dialog` で作る。

| 項目 | 値 |
|---|---|
| ボタン | 丸（999px）、高さ 32px 以上、余白 2px 10px、12px・`muted`・数字は等幅、アイコン 16px と文字の間 6px、枠は透明 |
| なぞる・フォーカス・開いている | 背景 `base`、文字 `text` |
| 失敗のとき | 文字とアイコンを `danger`（「同期に失敗（接続できません）」） |
| ポップオーバー | 幅 `min(360px, calc(100vw - 16px))`、余白 12px 14px、ほかは `docs/components.md` のメニューと同じ（角 10px・影）、ボタンの右端にそろえて下に出す |
| 中身 | 13px、間 10px。見出し 14px。1 件ずつ枠 `border`・角 8px・背景 `surface`・余白 8px 10px の箱に、名前（太さ 600）・最終の成功（`muted`）・失敗（`danger`）と、右に「今すぐ更新」（`secondary`・`small`） |

- 文字は短く、状態が分かるものにする（「同期 09:12」「同期に失敗（理由）」「同期: 停止中」）
- 599px 以下では文字を隠してアイコンだけにし、余白を 2px 8px に詰める。`aria-label` に状態の文を全部入れる（「同期の状態（同期 09:12）」）
- 中の「今すぐ更新」は `Form` と `SubmitButton` で送る（二重送信の防止）。結果は箱の下に 1 行で出し、失敗は `role="alert"`
- 設定が無いなど、出す意味がないときはボタンごと出さない

## 📊 表

数字や項目を並べて比べる画面の表（家計の集計、日ごとの記録など）。Markdown の本文の中の表とは別の部品にする。

| | 画面の表（`.data-table`） | 本文の表（`.prose table`） |
|---|---|---|
| 使いどころ | アプリが組み立てる一覧・集計 | 利用者が Markdown で書いた表 |
| 文字 | 13px | 本文の 0.94 倍、行の高さ 1.6 |
| セルの余白 | 6px 8px | 6px 12px |
| 線 | 行の下だけ `border` | すべてのセルに `border` の枠 |
| 見出しの行 | `surface`、太さ 600、折り返さない | `surface`、太さ 600 |
| 縞 | 付けない | 偶数行を `surface` の半分の濃さで塗る |
| 狭い画面 | 699px 以下で行ごとのカードに崩す | 表だけ横にスクロール（`display: block; overflow-x: auto`） |

- 数字（金額・時間・件数）は `font-variant-numeric: tabular-nums` で右寄せ、折り返さない。日付は左寄せ
- 2 段目の補足は 12px の `muted`、長い英数字は `overflow-wrap: anywhere`
- 予算を超えたなど目立たせる値は `danger` の文字で太さ 600（色だけに頼らず、合計や見出しで意味が分かるようにする）
- **カードに崩すとき**: `thead` を隠し、行を枠 `border`・角 10px・余白 6px 10px・背景 `base` のカードにする（間 8px）。各セルの頭に `data-label` の項目名（12px の `muted`、幅 6.5rem）を `::before` で出す。セルには必ず `data-label` を書く
- 表には `caption`（見えなくてよい）か、見出しとの `aria-labelledby` で名前を付ける。見出しのセルは `scope="col"`
- 横にスクロールする本文の表は、枠の中だけで動かし、ページ全体をはみ出させない

## 🍩 割合のドーナツ

分類ごとの割合を 1 つの輪で見せる（今日の時間の使い方など）。見本は `samples/patterns.html` の「割合のドーナツ」。

| 項目 | 値 |
|---|---|
| 大きさ | 180px 四方、輪の太さ 18px |
| 1 周 | 「目安と合計の大きい方」。合計が目安に満たないときは足りない分を描かず、下地の輪だけを見せる。超えたら合計を 1 周にする |
| 向き | 12 時から時計回り |
| 弧の間 | 2px のすき間。弧がすき間より短いときは半分の長さで描き、消さない（弧と凡例の数をそろえる） |
| 下地の輪 | `border` |
| 分類の色 | その他の配色の `dot`。今の見た目が暗いとき（`docs/color.md` の判定）は `dark.dot` |
| 色の無い分類・分類なし・その他 | `color-mix(in srgb, var(--color-muted) 50%, var(--color-base))` の淡い灰色（下地の輪より濃く、見分けられる） |
| 真ん中 | 合計を 20px・太さ 600、下に「/ 8:00」か、超えたら「（+1:15）」を 12px。どちらも `text`、等幅の数字 |
| 凡例 | 13px、行の高さ 32px 以上、余白 4px 8px、角 6px。左から印（10px の丸）・名前（1 行で省略）・時間・割合（右寄せ、等幅の数字） |

- **凡例は必ず付ける**。色だけで分類を伝えない。並びは弧と同じにする
- 並びは時間の多い順。「その他」と「分類なし」は最後に置く。0 分の分類は出さない
- **7 件以上**なら、分類のある上位 5 件を残し、残りと「分類なし」を「その他」にまとめる（6 件までは全部出す。6 件で「その他」1 件にまとめても意味がないため）。「その他」の凡例の行の `title` に、まとめた分類の名前を入れる
- 割合は合計に対する割合を整数に丸める。足して 100 にならないことがあるが、そのままにする
- 弧か凡例の行に乗せる（なぞる・凡例の行のフォーカス）と、ほかの弧を `opacity: 0.25`、ほかの凡例の行を `opacity: 0.45` に薄くし、真ん中をその分類の時間と「名前・割合」に替える。離れると合計に戻す
- 凡例の行は `tabindex="0"` にし、キーボードでも同じ動きにする（弧そのものにはフォーカスを置かない）
- SVG に `role="img"` と、全体の要約の `aria-label`（「今日の時間の使い方。合計 6:30、目安 8:00 まであと 1:30。暮らし 2:00（31%）、…」）。真ん中の文字は `aria-hidden`（要約と凡例で伝わるため）
- テーマが変わったら色を塗り直す。`data-theme` の変化（`MutationObserver`）と `prefers-color-scheme` の変化の両方を見張る
- 薄くする動きは 0.15s。`prefers-reduced-motion: reduce` では動かさない

## 📖 Markdown の本文

読むためのページの本文（`.prose`）と、欄の中で書いたメモを見せる小さい版（`.prose.prose--small`）の 2 つ。

| | 本文 | 小さい版 |
|---|---|---|
| 使いどころ | 本文を読むページ | 欄・カード・ダイアログの中のメモ |
| 文字・行の高さ | 16px・1.85 | 14px・1.7 |
| 見出し | h1 1.75em、h2 1.4em に `border` の下線、h3 1.2em。上に 2em・下に 0.6em | h1 18px、h2 16px、h3 以下 15px。下線なし |
| 段落などの間 | 下に 1em | 上下に 0.5em |
| 引用 | 左の線 4px、`muted` の文字 | 左の線 3px |
| 表 | 枠付き・縞あり | 枠付き・縞なし、13px、余白 4px 8px |

- **インラインのコード**: 等幅で 0.88em、余白 0.1em 0.35em、角 4px、`surface` の背景に `border` の枠。小さい版は枠なしで 13px
- **kbd**: 等幅で 0.85em、`surface` の背景、枠 `border` で下の枠だけ 2px（キーの厚み）
- **mark**: `warning-bg` の背景、文字は `text`
- **リンク**: `accent-strong`、下線は 0.2em 離す
- **折りたたみ（details）**: 枠 `border`・角 8px・`surface`、summary は太さ 600

## 🧮 列をそろえる一覧

一覧の行（カード）を表のように並べ、番号・題名・期日・時間・操作の各列の幅を、行の間でそろえる。見本は `samples/patterns.html` の「列をそろえる一覧」。

```css
.grid-list {
  display: grid; grid-template-columns: auto minmax(0, 1fr) auto auto auto;
  row-gap: 4px; margin: 0; padding: 0; list-style: none;
}
.grid-row {
  display: grid; grid-column: 1 / -1; grid-template-columns: subgrid;
  align-items: center; column-gap: 10px; padding: 6px 10px; position: relative;
}
@media (max-width: 599px) {
  .grid-list { grid-template-columns: minmax(0, 1fr); }
  .grid-row { grid-template-columns: auto minmax(0, 1fr) auto; grid-template-rows: auto auto; }
}
```

- 列は一覧（`.grid-list`）が決め、各行は `grid-template-columns: subgrid` でその列を共有する。行ごとの `display: flex` では、期日や時間の幅が行によって変わり、縦の線がそろわない
- 題名の列だけ `minmax(0, 1fr)`（1 行で省略）、ほかは `auto`（中身の一番広い行に合わせる）
- 操作の列は列の幅いっぱいにし、ボタンを右に寄せる（`justify-self: stretch; justify-content: flex-end`）。ボタンの少ない行も列の左端がそろう
- 行の見た目（枠・角・余白）は「一覧の行」と同じ。分類の色のマスの行のカード（`docs/components.md`）とも組み合わせられる
- **599px 以下ではカードに崩す**: 一覧を 1 列にし、行の中を「マス（2 段の高さいっぱい）／1 段目に題名／2 段目に期日・時間と操作」に並べ替える。横にはみ出させない
- 行は `<li>` のまま（`role="table"` にしない）。見た目だけを表にそろえる。列の見出しは出さない（期日・時間は中身で分かるため）

## 🪪 詳細のダイアログ

一覧の番号か題名を押すと、その項目の詳細を wide のダイアログ（880px）で開く。見本は `samples/patterns.html` の「詳細のダイアログ」。

- 上から: 見出し（17px、題名の全文。省略しない・`overflow-wrap: anywhere`）→ 分類のバッジと状態 → 項目の欄 → 本文 → ボタン
- **項目の欄**は定義リスト（`<dl>`）。項目名 13px・太さ 600・`muted`、値 14px。2 列（`minmax(6em, max-content) minmax(0, 1fr)`）、599px 以下は項目名と値を縦に重ねる
- **本文**は Markdown の小さい版（`.prose.prose--small`）で描く。描けないとき（Markdown でない・描く部品が読み込めない）はテキストのまま `white-space: pre-wrap` で出し、`http:`・`https:` で始まる URL だけをリンクにする（`javascript:` などは文字のまま）。利用者の書いた HTML はそのまま描かない
- **外部で開くボタン**（`secondary`、`ExternalLink`）は、その項目の元のページへ。`target="_blank"` と `rel="noopener noreferrer"`
- **関連する外部のリンクのボタン**（`ghost`・`small`、`Link`）は、本文や項目から拾った URL のうち、**https で、期待するホストのものだけ**を並べる（ホストは設定で決めた一覧と完全に一致させる。部分一致にしない）。それ以外の URL はボタンにしない
- 外側のクリックでは閉じない（ModalDialog の決まり）。閉じるのは「閉じる」のボタンと Esc
- 読み込み中は本文の位置に「読み込み中…」、失敗は失敗の帯。項目の欄は一覧で分かっている値を先に出してよい

# ♿ アクセシビリティ

## 🔍 コントラスト

- 文字は背景との比 4.5 以上（7 テーマすべて）。詳しくは `docs/color.md`
- アクセント `#859A93` は文字に使わない。ライトのテーマでベースとの比が 2.1〜2.9 しかない
- 色だけで意味を伝えない。状態にはアイコンか文字を添える（期日を過ぎた行は色に加えて日付を出す、プロジェクトの印は名前と並べる）
- 押せないボタンは `opacity: 0.55` で薄くするが、押せない理由が分かりにくいときは近くに文で書く

## ⌨️ キーボード操作

- ダイアログ・メニュー・タブ・トグル・選択など、キーボード操作や読み上げへの対応が難しい部品は **React Aria Components** を使う。自分で `div` に `onClick` を付けて作らない
- すべての操作を Tab と Enter / Space で行えること。メニューは矢印キーで動き、Esc で閉じる
- ダイアログが開いたらフォーカスを中に移し、閉じたら開いたボタンに戻す（React Aria が行う）。開いている間は後ろの画面を操作できない
- サイドバーの幅のつまみのような独自の操作は、矢印キーでも動かせるようにする（例: ←→ で 16px、Shift で 4 倍）

## 🏷️ aria と読み上げ

- アイコンは飾りとして `aria-hidden="true"`。アイコンだけのボタンには `aria-label`
- 入力欄はラベル・説明・エラーを結び付ける（`TextField`）。プレースホルダーをラベルの代わりにしない
- 送信中のボタンとフォームに `aria-busy`
- 失敗の帯は `role="alert"`。ダイアログで選択肢を選ぶまで閉じないものは `role="alertdialog"`
- 欄（`section`）や一覧の行には `aria-label` で名前を付ける。画面に出さない見出しは「読み上げだけに出す」クラス（`visuallyHidden`）で残す
- 切り替えのボタン（ピンなど）は `aria-pressed`、開け閉めは `aria-expanded`
- ナビには `aria-label="主なページ"` のように名前を付ける
- `<html lang="ja">`

## 🎯 フォーカスの見え方

```css
:focus-visible {
  outline: 2px solid var(--color-accent);
  outline-offset: 2px;
}
```

- キーボードで動かしたときだけ輪を出す（`:focus-visible`）。輪を消さない（`outline: none` は、React Aria の `data-focus-visible` などで代わりの見た目を付けるときだけ）
- 入力欄はフォーカス中に輪（オフセット 0）と枠を `accent` にする
- 注意: アクセントの輪は、ライトのテーマでベースとの比が 2.1〜2.9 で、WCAG の「文字以外のコントラスト」（1.4.11、3:1）にわずかに届かない。2px の太さと 2px の間で見分けはつくが、輪を `accent-strong` にするかは今後の検討事項（変えるときは各アプリと souan を同時に変える）

## 🎞️ 動き

- `prefers-reduced-motion: reduce` のときはスピナーの回転や引き出しの動きを止める
- 点滅や大きく動く飾りは使わない
